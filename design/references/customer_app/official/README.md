# Chamaê Delivery — Referências Visuais Oficiais do App Cliente

Estas imagens foram aprovadas como referência visual principal do app cliente.

Use como referência de composição, hierarquia, paleta, cards, bordas, sombras, headers, banners, navegação inferior, apresentação de produtos, carrinho, checkout, tracking e perfil.

Se houver conflito entre a imagem e uma regra funcional já aprovada, a regra funcional prevalece.

Não copiar literalmente dados fictícios das imagens, incluindo preços, fretes, tempos, nomes, telefones, placas, contagens, categorias ou produtos comercialmente bloqueados.
